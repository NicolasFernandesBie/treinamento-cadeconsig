# 🧠 Instruções para o Treinamento de Estagiários e Desenvolvedores do Cadê Consig

Bem-vindo(a) ao repositório de **desafios de treinamento**!  
Aqui você encontrará exercícios práticos para desenvolver suas habilidades e consolidar os fundamentos da programação e integração à empresa.

Siga atentamente as instruções abaixo para enviar suas soluções de forma organizada.

---

## 🚀 Passo a passo

### 1. Clone o repositório

Baixe o projeto para sua máquina:

```bash
git clone https://github.com/dkat-davi/treinamento-cadeconsig
```

---

### 2. Crie uma nova branch

Crie uma branch com o seguinte formato:

```
nome-do-desafio:seu-username-github
```

**Exemplo:**

```
simulador-credito:dkat-davi
```

---

### 3. Crie sua pasta dentro do desafio

Dentro da pasta do desafio correspondente, crie uma subpasta com o seu identificador (mesmo usado na branch).

**Exemplo:**

```
/simulador-credito/dkat-davi/
```

> 💡 Isso garante que cada participante tenha seu próprio espaço de trabalho sem sobrescrever o código dos outros.

---

### 4. Desenvolva sua solução

Implemente o desafio **seguindo as orientações** e requisitos descritos no enunciado.  
Você pode adicionar comentários explicativos e commits intermediários, se desejar.

---

### 5. Faça commit das suas alterações

Salve suas modificações localmente com uma mensagem clara e descritiva:

```bash
git add .
git commit -m "feat: implementação da simulação de crédito consignado"
```

---

### 6. Envie a branch para o repositório remoto

```bash
git push origin nome-da-branch
```

---

### 7. Abra um Pull Request

Ao finalizar o projeto, crie um **Pull Request** da sua branch para a branch **main**.  
Inclua no PR:

- Um breve resumo do que foi feito;
- Qual desafio você está entregando;

> ✅ Seu código será revisado e, se necessário, você receberá feedbacks para melhorias.

---

## 🧾 Boas práticas

- Use nomes de variáveis e commits descritivos.
- Teste seu código antes de enviar.
- Mantenha o código limpo e organizado.
- Não altere arquivos de outros participantes.

---

## 🏁 Dúvidas

Em caso de dúvidas, entre em contato com o responsável pelo treinamento.
